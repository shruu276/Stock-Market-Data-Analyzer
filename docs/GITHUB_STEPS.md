# 🔟 GITHUB UPLOAD STEPS

Follow these steps to upload your project to GitHub and make it a standout portfolio piece.

## 1. Prepare Local Repository
Make sure you have Git installed. Open your terminal in the project root folder.

```bash
git init
git add .
git commit -m "Initial commit: Stock Market Data Analyzer complete system"
```

## 2. Create Repository on GitHub
1. Go to GitHub and log in.
2. Click the `+` icon in the top right and select **New repository**.
3. **Repository Name:** `Stock-Market-Data-Analyzer` (or `QuantEdge-Analyzer`).
4. **Description:** "End-to-end Python pipeline and Next.js dashboard for ingesting, analyzing, and backtesting stock market data."
5. Set it to **Public**.
6. Do NOT check "Add a README" (since we already have one locally).
7. Click **Create repository**.

## 3. Connect and Push Code
Copy the commands provided by GitHub under "...or push an existing repository from the command line" and run them in your terminal.

```bash
git remote add origin https://github.com/yourusername/Stock-Market-Data-Analyzer.git
git branch -M main
git push -u origin main
```

## 4. Add Repository Tags
Once uploaded, go to the "About" section on your repository page (right sidebar), click the gear icon, and add the following tags:
`python`, `fastapi`, `nextjs`, `finance`, `data-analysis`, `stock-market`, `algorithmic-trading`, `pandas`

## 5. Upload Screenshots
Create an `images/` folder in your repository (or simply edit your README on GitHub and drag-and-drop the images). Add screenshots of your working dashboard to visually engage recruiters who visit your page.
